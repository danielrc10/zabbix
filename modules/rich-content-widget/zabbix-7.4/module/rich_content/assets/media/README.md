# Mídia local

Coloque aqui imagens autorizadas nos formatos PNG, JPEG, GIF, WebP ou SVG. Depois da instalação, referencie-as
como `modules/rich_content/assets/media/nome-do-arquivo.svg`.

Use nomes compostos somente por letras, números, ponto, hífen e sublinhado. Revise SVGs de terceiros antes de
copiá-los; prefira arquivos sem scripts, `foreignObject`, eventos ou referências remotas.
