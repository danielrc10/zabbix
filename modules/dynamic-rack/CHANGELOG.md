# Changelog

## 0.1.0 — 2026-08-26

- primeira versão funcional para Zabbix 7.4;
- racks de 1U a 48U, incluindo preset 8U;
- equipamentos monitorados, itens passivos, prateleiras e filhos em slots;
- indicadores em múltiplos balões e rodapé;
- cores herdadas do estado e layout de balões sem sobreposição;
- catálogos extensíveis de marcas e equipamentos;
- publicação dinâmica de host e item para outros widgets.
