# Catálogo de marcas

Adicione aqui arquivos `.svg`, `.png` ou `.webp` de até 128 KiB. O nome do arquivo aparece
automaticamente no editor do equipamento. Use somente imagens que você tenha permissão para usar.

Os arquivos incluídos são miniaturas tipográficas neutras para facilitar a identificação visual;
não substituem os arquivos oficiais das respectivas marcas.
