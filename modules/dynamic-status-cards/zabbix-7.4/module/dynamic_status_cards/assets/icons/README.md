# Ícones extensíveis / Extensible icons

## Português

Adicione nesta pasta arquivos SVG confiáveis com nomes formados por letras, números, hífen ou sublinhado. Os seletores do widget descobrem automaticamente arquivos `*.svg`, mostram a miniatura e salvam o nome escolhido para o cabeçalho ou para cada métrica. Use `viewBox="0 0 24 24"` e formas pretas; o widget usa o SVG como máscara e aplica a cor do estado.

Não copie SVGs de origem desconhecida. Embora sejam usados como máscara visual, administradores devem revisar o conteúdo antes da instalação.

## English

Add trusted SVG files to this directory using names made of letters, numbers, hyphens, or underscores. The widget selectors automatically discover `*.svg` files, display their preview, and store the chosen filename for the header or each metric. Use `viewBox="0 0 24 24"` and black shapes; the widget uses the SVG as a mask and applies the state color.

Do not copy SVG files from unknown sources. Even though they are used as visual masks, administrators should review their contents before installation.
