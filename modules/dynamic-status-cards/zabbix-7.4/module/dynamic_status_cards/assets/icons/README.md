# Ícones extensíveis / Extensible icons

## Português

Adicione nesta pasta arquivos SVG confiáveis com nomes formados por letras, números, hífen ou sublinhado. O seletor do widget descobre automaticamente arquivos `*.svg`, mostra a miniatura e salva o nome escolhido por métrica. Use `viewBox="0 0 24 24"` e formas pretas; o widget usa o SVG como máscara e aplica a cor do estado.

Não copie SVGs de origem desconhecida. Embora sejam usados como máscara visual, administradores devem revisar o conteúdo antes da instalação.

## English

Add trusted SVG files to this directory using names made of letters, numbers, hyphens, or underscores. The widget selector automatically discovers `*.svg` files, displays their preview, and stores the chosen filename per metric. Use `viewBox="0 0 24 24"` and black shapes; the widget uses the SVG as a mask and applies the state color.

Do not copy SVG files from unknown sources. Even though they are used as visual masks, administrators should review their contents before installation.
